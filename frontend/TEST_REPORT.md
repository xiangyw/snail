## 🚀 运行测试

### 组件测试

```bash
# 运行所有组件测试
npm run test

# 运行特定组件测试
npm run test -- Home.test.ts

# 运行测试并生成覆盖率报告
npm run test:coverage
```

### E2E 测试

```bash
# 安装 Playwright 浏览器
npx playwright install

# 运行所有 E2E 测试
npx playwright test

# 运行特定测试
npx playwright test app.spec.ts

# 以有头模式运行 (显示浏览器)
npx playwright test --headed

# 生成 HTML 报告
npx playwright test --reporter=html
```
