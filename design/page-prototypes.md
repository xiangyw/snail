# Snail 项目页面原型说明

> 版本：1.0.0  
> 最后更新：2026-03-30

---

## 一、首页布局 (Home Page)

### 1.1 页面结构

```
┌─────────────────────────────────────┐
│           顶部导航栏                  │
│  [头像] Snail 任务管理        [消息]  │
├─────────────────────────────────────┤
│                                     │
│         📊 今日概览卡片               │
│    ┌─────────────────────────┐      │
│    │  进行中  已完成  待处理   │      │
│    │    5       12       3    │      │
│    └─────────────────────────┘      │
│                                     │
├─────────────────────────────────────┤
│         🔥 快速操作区                 │
│    [新建任务] [扫码] [导入]          │
│                                     │
├─────────────────────────────────────┤
│         📋 任务列表                   │
│    ┌─────────────────────────┐      │
│    │ ○ 任务项 1        [状态] │      │
│    │ ○ 任务项 2        [状态] │      │
│    │ ○ 任务项 3        [状态] │      │
│    │ ...                     │      │
│    └─────────────────────────┘      │
│                                     │
├─────────────────────────────────────┤
│         底部导航栏                    │
│   [首页] [任务] [统计] [我的]        │
└─────────────────────────────────────┘
```

### 1.2 组件详情

#### 顶部导航栏
- 高度：44px
- 背景：#FFFFFF
- 左侧：用户头像 (32px) + 用户名
- 右侧：消息图标 (带红点提示)
- 固定定位，滚动时保持可见

#### 今日概览卡片
- 背景：渐变背景 (snail-gradient-bg)
- 内边距：16px
- 圆角：12px
- 三列布局：进行中/已完成/待处理
- 数字：24px，加粗，主色
- 标签：12px，次要文字

#### 快速操作区
- 布局：横向滚动或网格
- 按钮样式：图标 + 文字
- 图标尺寸：24px
- 文字：12px

#### 任务列表
- 列表项高度：64px
- 左侧：复选框 (20px)
- 中间：任务标题 (14px) + 描述 (12px，灰色)
- 右侧：状态标签/操作按钮
- 分割线：1px，#F0F0F0

#### 底部导航栏
- 高度：50px + 安全区
- 背景：#FFFFFF，顶部 1px 边框
- 4 个 Tab 均分
- 图标：24px
- 文字：10px
- 激活状态：主色

### 1.3 交互说明

- 下拉刷新：更新任务列表
- 任务项左滑：显示删除/编辑操作
- 点击任务项：进入任务详情
- 点击新建任务：弹出创建表单
- 底部 Tab 切换：页面切换动画 (fade)

### 2.3 组件详情

#### 筛选标签栏
- 布局：横向滚动
- 标签样式：胶囊形
- 未选中：灰色背景，灰色文字
- 选中：主色背景，白色文字
- 内边距：8px 16px

#### 任务分组
- 分组标题：14px，加粗，带日期图标
- 分组内任务：标准列表项
- 分组间距：16px

#### 浮动新建按钮 (FAB)
- 尺寸：56px × 56px
- 位置：右下角，距底部 80px，距右边 16px
- 背景：主色渐变
- 图标：+ 号，白色，24px
- 阴影：shadow-lg

### 2.4 交互说明

- 搜索框：实时搜索，防抖 300ms
- 筛选标签：点击切换，带动画
- 子任务复选框：点击完成/取消
- 附件：点击预览/下载
- FAB 按钮：点击弹出创建表单

## 四、通用页面元素

### 4.1 空状态 (Empty State)

```
┌─────────────────────────────────────┐
│                                     │
│           [空状态图标]               │
│                                     │
│         暂无数据                     │
│    这里还没有任何内容               │
│                                     │
│         [操作按钮]                   │
│                                     │
└─────────────────────────────────────┘
```

- 图标尺寸：80px
- 标题：16px，#333333
- 描述：14px，#999999
- 按钮：主色按钮

### 4.2 加载状态 (Loading)

- 列表加载：骨架屏
- 下拉刷新：旋转 loading 图标
- 页面切换：fade 过渡

### 4.3 错误状态 (Error)

```
┌─────────────────────────────────────┐
│           [错误图标]                 │

│    请检查网络连接后重试             │
│         [重试按钮]                   │
└─────────────────────────────────────┘
```

| 卡片最小高度 | 100px |
| 列表项最小高度 | 44px |
| 按钮最小高度 | 40px |
