# Snail Design - Logo 使用指南

## 📁 文件说明

本目录包含 Snail 项目的所有 Logo 资源。

## 🎨 Logo 文件

| 文件 | 用途 | 尺寸 |
|------|------|------|
| `logo-horizontal.svg` | 横版 Logo（矢量） | 可缩放 |
| `logo-horizontal.png` | 横版 Logo（位图） | 2000x500px |
| `logo-icon.svg` | 图标 Logo（矢量） | 可缩放 |
| `logo-icon.png` | 图标 Logo（位图） | 512x512px |
| `favicon.ico` | 网站图标 | 32x32px |

## 🎯 使用场景

### 横版 Logo
- 网站首页
- 邮件签名
- 官方文档
- 宣传材料

### 图标 Logo
- App 图标
- 社交媒体头像
- 浏览器标签页
- 小尺寸展示

## 📐 最小尺寸

- **横版 Logo**: 高度不小于 24px
- **图标 Logo**: 不小于 16x16px

## 🚫 使用规范

1. 不要更改 Logo 颜色（除非使用单色版本）
2. 不要拉伸或变形 Logo
3. 保持足够的安全边距
4. 不要在复杂背景上使用
