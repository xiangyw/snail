# Snail Templates - 设计模板

## 📁 目录说明

本目录提供设计模板文件，方便设计师快速开始。

## 📦 可用模板

### Figma 模板
- **位置**: `templates/figma/`
- **内容**:
  - UI 组件库
  - 页面模板
  - 设计规范
  - 自动布局组件

### Sketch 模板
- **位置**: `templates/sketch/`
- **内容**:
  - Symbols 库
  - 页面模板
  - 样式指南

### Adobe XD 模板
- **位置**: `templates/xd/`
- **内容**:
  - Components 库
  - 重复网格组件
  - 原型模板

## 🎨 模板内容

### UI 组件库
包含所有 Vant 组件的设计稿：
- 按钮
- 表单
- 卡片
- 列表
- 导航
- 弹窗
- 标签页

### 页面模板
常用页面的设计模板：
- 首页
- 列表页
- 详情页
- 个人中心
- 登录/注册

### 设计规范
- 色彩系统
- 字体规范
- 间距规范
- 图标规范

## 📥 使用方法

1. 下载对应工具的模板文件
2. 在您的设计工具中打开
3. 基于模板开始设计
4. 保持与设计规范一致
