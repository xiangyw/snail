## 3. 测试策略

### 3.1 测试类型

| 测试类型 | 工具 | 覆盖率目标 |
|----------|------|------------|
| 单元测试 | Vitest | 80%+ |
| 组件测试 | Vue Test Utils | 80%+ |
| API 测试 | Axios Mock | 100% |
| E2E 测试 | Playwright | 核心流程 |
| WebSocket 测试 | Mock WebSocket | 100% |

### 3.2 测试优先级

#### P0 - 阻塞性测试 (必须通过)
- 消息列表加载
- 消息发送功能
- WebSocket 连接
- 未读计数显示

#### P1 - 重要测试 (应该通过)
- 消息分类切换
- 消息详情展示
- 标记已读功能
- 断线重连

#### P2 - 增强测试 (可以延后)
- 删除消息功能
- 图片/链接渲染
- 下拉刷新动画
- 性能优化
