## 测试执行说明

### 后端测试
```bash
cd snail-backend
mvn test -Dtest=ContentControllerIntegrationTest
mvn test -Dtest=ContentServiceTest
mvn test -Dtest=ContentRepositoryTest
mvn test -Dtest=ContentTest
```

### 前端测试
```bash
cd snail-frontend
npm install
npm run test
npm run test:coverage
```

### E2E 测试
```bash
cd snail-frontend
npx playwright install
npx playwright test
```
