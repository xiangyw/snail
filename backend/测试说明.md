# Snail 后端测试说明

## 快速开始

### 前置条件
- Java 17+
- Maven 3.6+

### 运行所有测试
```bash
cd snail-backend
mvn test
```

### 运行特定测试类
```bash
# 认证 API 测试
mvn test -Dtest=AuthControllerIntegrationTest

# 任务 API 测试
mvn test -Dtest=TaskControllerIntegrationTest

# 用户任务 API 测试
mvn test -Dtest=UserTaskControllerIntegrationTest

# 积分 API 测试
mvn test -Dtest=PointTransactionControllerIntegrationTest

# 用户管理 API 测试
mvn test -Dtest=UserControllerIntegrationTest
```

### 运行单个测试方法
```bash
mvn test -Dtest=AuthControllerIntegrationTest#testLogin_Success
```

### 生成测试覆盖率报告
```bash
mvn clean test jacoco:report
# 报告位于：target/site/jacoco/index.html
```

### 生成 Surefire 报告
```bash
mvn surefire-report:report
# 报告位于：target/site/surefire-report.html
```

## Postman 测试集合

导入 `snail-api-tests.postman_collection.json` 到 Postman：

1. 打开 Postman
2. 点击 Import
3. 选择 `snail-api-tests.postman_collection.json`
4. 设置环境变量变量 `baseUrl` (默认：http://localhost:8080)
5. 运行集合

### Postman 集合变量

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| baseUrl | API 基础地址 | http://localhost:8080 |
| accessToken | 普通用户 Token | eyJhbGciOiJIUzI1NiIs... |
| adminToken | 管理员 Token | eyJhbGciOiJIUzI1NiIs... |
| testUserId | 测试用户 ID | 1 |
| testTaskId | 测试任务 ID | 1 |

## 测试用例设计原则

### 认证 API
- ✅ 正常流程：注册、登录、登出
- ✅ 异常流程：重复注册、错误密码、用户不存在
- ✅ 边界条件：空密码、无效邮箱
- ✅ 安全测试：未授权访问、Token 验证

### 任务 API
- ✅ CRUD 操作完整性
- ✅ 权限控制：管理员 vs 普通用户
- ✅ 数据验证：必填字段、状态枚举

### 用户任务 API
- ✅ 任务分配流程
- ✅ 任务完成流程
- ✅ 状态流转：ASSIGNED → IN_PROGRESS → COMPLETED

### 积分 API
- ✅ 积分流水查询
- ✅ 权限隔离：用户只能查自己的
- ✅ 管理员查看全部

### 用户管理 API
- ✅ 管理员专属功能
- ✅ 权限验证
- ✅ 数据一致性

## CI/CD 集成示例

### GitHub Actions
```yaml
name: Java CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up JDK 17
        uses: actions/setup-java@v3
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Test with Maven
        run: mvn test
      - name: Upload coverage reports
        uses: codecov/codecov-action@v3
```

### Jenkins Pipeline
```groovy
pipeline {
    agent any
    stages {
        stage('Test') {
            steps {
                sh 'mvn test'
            }
            post {
                always {
                    junit 'target/surefire-reports/*.xml'
                }
            }
        }
    }
}
```

## 常见问题

### Q: 测试失败 "Connection refused"
A: 确保后端服务未运行，集成测试使用内嵌数据库，不需要外部服务。

### Q: 如何调试测试？
A: 在 IDE 中右键测试类 → Debug，或使用 `mvnDebug test`。

### Q: 测试执行太慢？
A: 检查是否有不必要的数据库操作，考虑使用 `@DataJpaTest` 进行更细粒度的测试。
