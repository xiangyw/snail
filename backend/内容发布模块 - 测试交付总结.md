## 📝 测试方法说明

### 如何运行测试

#### 后端测试
```bash
cd snail-backend

# 运行所有测试
mvn test

# 运行内容模块测试
mvn test -Dtest=ContentControllerIntegrationTest
mvn test -Dtest=ContentServiceTest
mvn test -Dtest=ContentRepositoryTest
mvn test -Dtest=ContentTest

# 生成覆盖率报告
mvn clean test jacoco:report
```

#### 前端单元测试
```bash
cd snail-frontend

# 安装依赖
npm install

# 运行测试
npm run test

# 运行测试并生成覆盖率
npm run test:coverage

# 运行测试 UI
npm run test:ui
```

#### E2E 测试
```bash
cd snail-frontend

# 安装 Playwright 浏览器
npx playwright install

# 运行所有 E2E 测试
npx playwright test

# 运行特定测试
npx playwright test publish-flow
npx playwright test content-browsing

# 生成 HTML 报告
npx playwright test --reporter=html
```
