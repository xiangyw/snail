## 📋 模块小组工作流程

### 开发阶段
```
1. 需求理解 (5 分钟)
   ↓
2. 代码开发 (20-30 分钟)
   ↓
3. 开发自测 (5 分钟)
   ↓
4. 提交测试 (自动通知测试工程师)
```

### 测试阶段
```
1. 接收测试任务
   ↓
2. 运行自动化测试 (5 分钟)
   ↓
3. 手动验证 (5 分钟)
   ↓
4. 生成测试报告 (2 分钟)
   ↓
5. 如有 Bug → 返回开发修复
   ↓
6. 测试通过 → 提交项目经理
```

### 联调阶段
```
前后端都完成后:
1. API 对接测试 (10 分钟)
   ↓
2. 完整流程测试 (10 分钟)
   ↓
3. 性能测试 (5 分钟)
   ↓
4. 联调通过 → 提交 Git
```

## 📞 沟通协调

### 小组内沟通
- 开发 ↔ 测试：直接沟通，快速修复 Bug
- 使用 `@mention` 通知对方

### 跨小组沟通
- 前后端接口对接：通过 API 文档
- 路由冲突：前端负责人协调
- 实体冲突：后端负责人协调

### 问题上报
- 小组内无法解决 → 项目经理
- 技术难题 → 技术文档参考
- 需求不明确 → 需求文档参考
