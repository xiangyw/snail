## 🚀 快速开始

### 前置要求

- Node.js >= 18
- Java >= 17
- Docker >= 24
- Git

### 克隆项目

```bash
git clone https://github.com/xiangyw/snail.git
cd snail
```

---

## 🛠️ 技术栈

### 前端
- Vue 3 + TypeScript
- Vite
- Pinia (状态管理)
- Vue Router
- Element Plus / Ant Design Vue

### 后端
- Java 17
- Spring Boot 3
- MyBatis Plus / JPA
- MySQL / PostgreSQL
- Redis

### 运维
- Docker + Docker Compose
- GitHub Actions (CI/CD)
